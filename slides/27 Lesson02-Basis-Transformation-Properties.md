At this juncture we state some facts about coordinate transformation matrices.

1. A coordinate transformation matrix is always square
2. A coordinate transformation matrix obviously has an inverse
3. A coordinate transformation matrix inverse is denoted $A^{-1}$ with property $AA^{-1}=A^{-1}A=Id$


Where $Id$ is the identity matrix which has one's on the diagonal and zeros elsewhere. As this example of a $3x3$ matrix indicates

$$
Id=
\,
\begin{bmatrix}
1& 0&0\\
0&1&0\\
0&0&1
\end{bmatrix}
$$
So if the matrix $A$ transforms from one set of coordinates to another the inverse transforms the other way.
