<h3 style="color: blue;">Span of a set</h3>
Let $V$ be a vector space let $U\subset V$ be a subset of $V$


The span of the set $U$, $\operatorname{span}(U)$ is defined as
the **intersection** of all subspaces of V that contain U

Or equivalently the more operational statement. 

$\operatorname{span}(U)=$ the set of **all finite** linear combinations from the set $U$

This set $\operatorname{span}(U)$ is itself a subspace of the vector space $V$.

Try to convince yourselves that this is correct.
