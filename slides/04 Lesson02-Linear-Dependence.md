<h3 style="color: blue;">Linear Dependence</h3>

Let $V$ be a vector space. A subset $U \subset V$ is said to be linear dependent if it is **not independent**


That is there exist a finite set of vectors $ \mathbf{v}_1,\mathbf{v}_2,\dots,\mathbf{v}_n $


and scalars $ c_1,c_2,\dots, c_n $ **not all** 0 such that


$c_1\mathbf{v}_1,c_2\mathbf{v}_2,\dots,c_n\mathbf{v}_n=\mathbf{0}$


Which means that one of the vectors can be written as a linear combination of the others. Say that $c_k\neq 0$ then


$ \mathbf{v}_k= \frac{c_1}{c_k}\mathbf{v}_1+\frac{c_2}{c_k}\mathbf{v}_2+\dots +\frac{c_{k-1}}{c_k}\mathbf{v}_{k-1}+\dots +\frac{c_{k+1}}{c_k}\mathbf{v}_{k+1}+\dots + \frac{c_{n}}{c_k}\mathbf{v}_{n}$
