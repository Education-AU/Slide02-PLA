We have seen one example of an infinite dimensional vector space but as stated earlier we will concentrate on the vector
space $\mathbb{R}^n$, which is as we saw is finite dimensional.

In this case we have further theorems

1. **Any linear independent set of size** $n$ **is a basis**
2. **Any set of linear independent vectors can be extended to a basis of size** $n$

We saw an example of theorem **2** in an earlier exercise
